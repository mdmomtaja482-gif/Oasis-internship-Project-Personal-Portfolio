# 💻 Personal Portfolio Website

A modern, responsive **personal portfolio website** designed to showcase my skills, education, experience, projects, and professional journey. The website is built using **HTML5, CSS3, and Vanilla JavaScript** with a clean and modern cyan-blue interface.

## 🌐 Overview

This portfolio provides a professional online presence where visitors can explore my:

* 👨‍💻 Introduction
* 🎓 Education
* 🛠️ Technical Skills
* 💼 Experience
* 🚀 Projects
* 📩 Contact Information

The website is fully responsive and includes interactive features such as **Dark Mode, Mobile Navigation, Scroll Reveal, Active Navigation, Back-to-Top Button, and Contact Form Validation**.

## ✨ Features

* 📱 Fully Responsive Design
* 🌙 Dark / Light Mode
* 🍔 Responsive Mobile Navigation Menu
* 📌 Sticky Navigation Header
* 🔄 Active Navigation on Scroll
* ✨ Scroll Reveal Animations
* ⬆️ Back-to-Top Button
* 📩 Contact Form Validation
* 🔔 Toast Notifications
* ♿ Keyboard-friendly interactions
* 🎨 Modern Cyan/Blue UI
* ⚡ Lightweight Vanilla JavaScript
* 💾 Theme Preference saved using LocalStorage

The JavaScript implementation handles theme persistence, mobile navigation, scroll behavior, active-section detection and form validation.

## 🛠️ Technologies Used

| Technology                    | Purpose                                           |
| ----------------------------- | ------------------------------------------------- |
| **HTML5**                     | Website structure and semantic content            |
| **CSS3**                      | Styling, layout, animations and responsive design |
| **JavaScript**                | Interactivity and dynamic behavior                |
| **LocalStorage**              | Saving theme preference                           |
| **Intersection Observer API** | Scroll reveal and active navigation               |
| **SVG**                       | Icons and UI elements                             |

The design uses a cyan/blue color system and supports a dedicated dark theme.

## 📄 Main Files

### `index.html`

Contains the complete structure of the portfolio website, including navigation, portfolio sections, theme toggle and responsive menu.

### `style.css`

Contains the complete visual design, responsive layouts, typography, buttons, animations, dark mode and other UI components.

### `script.js`

Handles all interactive functionality such as:

* Dark/Light theme
* Mobile menu
* Scroll effects
* Active navigation
* Scroll reveal
* Back-to-top functionality
* Contact form validation
* Toast messages
* Automatic footer year

The contact form validates name, email and message before submission.
